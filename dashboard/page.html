weighted tokens

Weighted tokens are cost expressed in input tokens of the reference model, using Anthropic's API prices per model, with 1-hour and 5-minute cache writes priced separately. They track your plan limits better than raw tokens, which are mostly cheap cache reads. Anthropic does not publish exactly how subscription limits are counted, so treat this as an approximation. "$" is the same usage at API prices; on a subscription you are not billed this.
