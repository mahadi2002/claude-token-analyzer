# Changelog

## 0.1.0 (2026-10-21)
- First public release.
- Day, Week, Month, Year and All-time views with efficiency ring, trend tiles and charts.
- Hour-by-hour chart with 5-hour usage windows.
- Token-leak analyzer: context bloat, old session resumed, duplicate session, polling loop, context overflow.
- Rule-based daily report (no tokens used).
- Once-a-day background refresh on session start.
- `/token-analyzer:usage` command and a usage-questions skill.
